# 退出与活动变更更新：文字检查

本文档帮助两人团队确认活动报名规则，并为后续架构、故事和测试提供可引用依据。本次按人类读者审查现有结构中的表达，仅覆盖退出、活动变更和候补补录更新；前序结构检查无发现，不存在须跳过或并入其他位置的段落。

有意保留的表达方式：简洁的中文需求规格语气、FR/NFR 编号引用、明确区分参加审核与退出审核的术语、状态和名额后果的重复强调，以及 `[ASSUMPTION A-n]`、建议与待确认等证据边界标记。它们服务于规则理解，不作偏好性润色。

**无实际妨碍理解的文字发现。** 本次更新能够清楚区分未入名单撤回、自由退出、待审退出与退出获批；“待审仍占位”和真正释放后按当前模式处理没有指代混乱。变更前成功名单、退出待审通知对象、整场取消与个人退出均有明确说明；队列按原申请时间优先、未入名单保序、禁止新申请插队及开放的截止细则表达可理解。新增取消后个人动作和同时间排序建议保留假设标签，没有因文字压缩混成已确认结论。

共享检查的 `word_metrics.py` 计量为总量 8,543 words（中文按脚本口径计）；本轮未作改写或字数变更。建议数：0。本报告对应当前修订，不覆盖或改写历史评审，也不将开放业务决定当成措辞错误。
