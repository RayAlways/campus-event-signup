# 报名流程参考核查

检索日期：2026-11-25。仅核查 Luma 官方帮助；以下为对照事实，不作为本项目需求。

## 来源事实

- [报名流程](https://help.luma.com/p/event-registration-process)：无需审核时提交即确认；需审核时通过才确认，待审核邮件说明名额尚未确认。报名可手动关闭、按截止时间关闭，或满额关闭。
- [候补与容量](https://help.luma.com/p/waitlist)：仅已通过者计入容量；开启候补后满额新申请进入候补。有人取消也不会自动递补，须主办方手动批准。

## 可用于澄清的问题（不是需求建议）

1. 本项目满额后直接阻止报名，还是仍接受审核申请？是否明确排除候补功能？
2. 已通过者取消后，先到先得模式是否立即释放名额？审核模式由谁、何时补录？
3. 报名截止后能否处理已提交的申请？活动取消时各报名状态如何结束？
4. 学生端如何区分“申请已提交”和“报名成功”；是否需要站内状态提示或通知？

已确认的“不占位待审核、通过占位、发布后模式不可变”无需再次询问。参考产品的通知渠道、候补及其他政策不自动纳入范围。
