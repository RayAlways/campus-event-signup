# 班级与社团活动报名管理

本项目用于 BMAD 与敏捷过程课程设计，提供活动发布与修改、两种报名模式、名单、按策略退出、公告和站内通知。发布后可切换报名模式；审核切为先到先得时，早先有效申请按时间优先录入，满额者保留顺序，空位后自动补录。未入名单可撤回；已入名单者按发起者设置自由退出，或提交理由经审核后退出，退出真正生效才释放名额。

当前完成选题、产品简报及 BMAD 6.12.1 项目配置，PRD 已于 2026 年 11 月 26 日形成需求基线，架构与 8 条 ADR 已有快速初稿。已创建公开 GitHub 仓库（主分支为 main），尚未开发软件。用户已选高层技术组合，其余技术建议与保留项明确标注；真实使用者访谈和试用仍未开展。

仓库地址：[RayAlways/campus-event-signup](https://github.com/RayAlways/campus-event-signup)。
