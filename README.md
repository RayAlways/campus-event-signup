# 班级与社团活动报名管理

本项目用于 BMAD 与敏捷过程课程设计，目标是为班级或社团提供活动发布、限额报名、取消报名和名单管理功能。每场活动由发起者选择先到先得或发起者审核模式，发布后固定。审核模式下，待审核申请不占名额，审核通过时才占用；已成功报名者取消后释放名额。

当前完成选题、产品简报、PRD 初稿及 BMAD 6.12.1 项目配置，已创建公开 GitHub 仓库（主分支为 main），尚未开发软件。PRD 采用快速初稿方式，用户已确认的规则与待审阅假设分开标注，尚未冻结为开发基线；真实使用者访谈和试用仍未开展。

仓库地址：[RayAlways/campus-event-signup](https://github.com/RayAlways/campus-event-signup)。
