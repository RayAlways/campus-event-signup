# 班级与社团活动报名管理

本项目用于 BMAD 与敏捷过程课程设计，目标是为班级或社团提供活动发布、限额报名、取消报名和名单管理功能。报名采用先到先得规则，取消后释放名额。

当前完成选题、产品简报初稿及 BMAD 6.12.1 项目配置，已创建公开 GitHub 仓库（主分支为 main），尚未开发软件。需求来自课程要求与组员初步选择，尚未经过真实使用者访谈或试用验证。

仓库地址：[RayAlways/campus-event-signup](https://github.com/RayAlways/campus-event-signup)。
