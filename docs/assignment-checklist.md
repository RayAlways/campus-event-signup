## 实验 A 记录口径

从项目中选择难度相当的故事 X 和 Y，并解释可比性。X 使用 PRD、架构、ADR、项目规则与故事卡；Y 使用干净会话，只描述需求而不提供上游产物。按课件要求保持同一操作者、同一天、同一宿主与模型，采用相同代码评审标准。

五项指标为会话轮数、代码评审首轮通过率、违反项目规则的次数、与 ADR 冲突的实现次数、返工故事数。课件度量表将首项解释为从开始到 done 开了几次对话；实施前应记录统一口径，并可另外保存会话内往返数。只有一个故事时，通过率与返工故事数的取值有限，应在报告中说明，不夸大差异。

另建议记录规划、实现、评审与返工耗时，用于讨论成本收益。样本量小、没有随机化，以及先做任务带来的熟悉效应等限制应如实说明；不为得到正结果改变评审标准。
